Projeto ONG — Desenvolvimento Front-End para Web

Descrição

Site desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Front-End para Web, com o objetivo de apresentar uma ONG fictícia, divulgar projetos sociais e disponibilizar um formulário de cadastro de colaboradores.

Tecnologias utilizadas

HTML5

CSS3

JavaScript

Git e GitHub

GitHub Pages

Funcionalidades

Página inicial com apresentação da ONG.

Página de projetos sociais com seções de Doações e Voluntariado.

Formulário de cadastro de colaboradores.

Menu de navegação responsivo.

Interações desenvolvidas com JavaScript.

Acessibilidade

O projeto utiliza elementos semânticos HTML, rótulos nos campos do formulário, textos alternativos em imagens e recursos de navegação por teclado. Foram implementadas melhorias com referência às diretrizes WCAG 2.1.

Estrutura do projeto

html/ — páginas do site.

css/ — estilos e responsividade.

js/ — scripts e funcionalidades.

imagens/ — recursos visuais.

Execução

Acesse o site publicado pelo GitHub Pages ou execute o projeto utilizando um servidor HTTP local.
